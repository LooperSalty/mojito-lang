# 🍹 Mojito pour VS Code

Écris des programmes **100 % emoji** dans de simples fichiers texte `.emoji` (ou `.moj`).

- **Exécuter** : bouton ▶ en haut de l'éditeur, ou <kbd>Ctrl</kbd>+<kbd>F5</kbd>. Le programme tourne dans le terminal « 🍹 Mojito » : on y tape les entrées `🎤`, <kbd>Ctrl</kbd>+<kbd>C</kbd> l'arrête. Aucune installation de Node.js n'est nécessaire, même pour un brouillon pas encore enregistré.
- **Erreurs en direct** : soulignées en rouge pendant que tu tapes, avec un message en français.
- **Survol** : passe la souris sur un emoji pour savoir ce qu'il fait (`🤔` → si, `🔂` → pour chaque…).
- **Voir le JavaScript généré** : bouton `</>` en haut de l'éditeur (vue en lecture seule, mise à jour en direct).
- **Compiler** : clic droit › *Mojito : Compiler en JavaScript autonome* produit un `.js` lançable avec `node`.
- **Snippets** : tape un mot français puis <kbd>Tab</kbd> — `si`, `sisinon`, `pour`, `tantque`, `fonction`, `var`, `affiche`, `plus`, `egal`, `n7`…
- **Nouveau fichier** : *Fichier › Nouveau fichier… › Programme Mojito (.emoji)*.

Réglage : `mojito.asciiNumbers` affiche `42` au lieu de `4️⃣2️⃣`.
